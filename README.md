### Реализованный функционал (Основное и дополнительные задания):

1. **Основное задание — Приоритетная очередь (Priority Queue):**
   * Упорядоченная вставка по приоритету (`pq_enqueue`): элемент с большим приоритетом становится перед элементом с меньшим приоритетом.
   * Сохранение дисциплины FIFO при равенстве приоритетов.
   * Извлечение элемента с наивысшим приоритетом из вершины за время $O(1)$ (`pq_dequeue`).
   * Функции поиска (`pq_find`) и удаления (`pq_del`) произвольного элемента по наименованию.
   * Полная очистка памяти (`pq_clear`).

2. **Дополнительное задание 1 (*) — Очередь (Queue — FIFO):**
   * Добавление элемента в хвост очереди (`queue_enqueue`).
   * Извлечение первого поступившего элемента из головы (`queue_dequeue`).
   * Просмотр содержимого от головы к хвосту (`queue_review`) и очистка (`queue_clear`).

3. **Дополнительное задание 2 (*) — Стек (Stack — LIFO):**
   * Помещение элемента в вершину стека (`stack_push`).
   * Извлечение последнего добавленного элемента из вершины (`stack_pop`).
   * Просмотр содержимого от вершины к основанию (`stack_review`) и очистка (`stack_clear`).

4. **Базовый односвязный список:**
   * Реализация базовых функций из методического пособия (`spstore`, `review`, `find`, `del`, `get_struct`).

5. **Пользовательский интерфейс:**
   * Интерактивное текстовое меню (пункты 0–12) с корректной русификацией (Windows-1251).
   * Автоматический демонстрационный режим (пункт 1), пошагово тестирующий все структуры без ручного ввода.

### Как открыть и запустить проект в Visual Studio:
1. Скачайте репозиторий (кнопка **Code → Download ZIP** или через `git clone`).
2. Дважды кликните по файлу **`alg3lr.sln`** (или `alg3lr.slnx`).
3. Проект откроется в Visual Studio со всеми преднастроенными свойствами сборки.
4. Нажмите **`Ctrl + F5`** (или кнопку «Локальный отладчик Windows») для компиляции и запуска программы.
