### Разделение заданий:

1. **Основной проект (`alg3lr.sln`):**
   * Содержит реализацию **Приоритетной очереди (Priority Queue)**: упорядоченная вставка по приоритету, извлечение элемента с максимальным приоритетом за $O(1)$, сохранение порядка FIFO при одинаковом приоритете, поиск и удаление узлов, а также базовый односвязный список.

2. **Проект с дополнительными заданиями (`лаба 3 алг (код с доп заданиями)/alg3lr_доп_задания.sln`):**
   * Включает **все дополнительные задания со звёздочками (`*`)**:
     * **Стек (Stack — LIFO)**: операции `push` в вершину, `pop` из вершины, просмотр и очистка.
     * **Очередь (Queue — FIFO)**: операции `enqueue` в хвост, `dequeue` из головы, просмотр и очистка.
     * **Приоритетная очередь**: полный функционал.
     * **Автоматический демонстрационный режим** проверки всех трех структур.

### Как открыть и запустить любой из проектов в Visual Studio:
* Чтобы запустить **основное задание**: дважды кликните по **`alg3lr.sln`** в корне.
* Чтобы запустить **код с дополнительными заданиями**: перейдите в папку `лаба 3 алг (код с доп заданиями)` и дважды кликните по **`alg3lr_доп_задания.sln`**.
* Для компиляции и запуска нажмите **`Ctrl + F5`**.
